# Promotions and vouchers

- Only one voucher can be used per order.
- Vouchers cannot be applied after an order has been paid.
- Voucher value is not refunded in cash. If an order with a voucher is returned, the refund equals the amount actually paid.
- Expired vouchers cannot be reactivated.
